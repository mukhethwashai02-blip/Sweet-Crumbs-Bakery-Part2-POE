

## 1. Project Overview

Sweet Crumbs Bakery is a website created for a small bakery business. The website allows customers to view bakery products, learn about the business, send order enquiries and contact the bakery.

The website was developed using HTML, CSS and JavaScript. It was improved throughout Part 1, Part 2 and Part 3 of the project.

The main aim of the website is to make it easier for customers to find information about the bakery and communicate with the business.

## 3. Website Pages

The website contains five main pages.

### 3.1 Home Page – index.html
The home page welcomes customers to Sweet Crumbs Bakery and introduces the business.

### 3.2 About Us Page – about.html
This page provides information about the bakery and its purpose.

### 3.3 Menu Page – services.html
This page displays the bakery products and allows customers to search for products. It also includes a frequently asked questions section.

### 3.4 Order Now Page – enquiry.html
This page allows customers to send order enquiries. JavaScript checks the information entered and calculates the estimated order cost.

### 3.5 Contact Page – contact.html
This page allows customers to contact the bakery using a contact form. It also includes location information and Google Maps.

## 6. Part 3 JavaScript Features

### 6.1 Product Search

A product search feature was added to help customers find bakery products.

Customers can type a product name into the search box. JavaScript checks the products and displays the matching results.

If a product cannot be found, a message is displayed.

### 6.2 Image Gallery Lightbox

A gallery lightbox was added to allow customers to view larger product pictures.

When a customer clicks a supported product image, a larger version opens. The customer can close the lightbox after viewing the picture.

### 6.3 Order Enquiry Form

The Order Now page contains a form where customers can enter their details and select products.

JavaScript is used to:

- Check that required information is entered.
- Validate customer information.
- Read the selected product and quantity.
- Calculate the estimated order cost.
- Display a response after the form is submitted.

This helps customers understand their estimated order amount.

### 6.4 Contact Form

The Contact Us page contains a form where customers can enter their name, email address and message.

JavaScript checks that the required information has been entered correctly.

EmailJS was added to support sending contact messages through email. An automatic reply was also configured for customers.

### 6.5 Frequently Asked Questions

A frequently asked questions section was added to the website.

Customers can open a question to read the answer and close it again.

This makes it easier for customers to find useful information.
